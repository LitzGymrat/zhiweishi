# 项目到底是什么

## 项目概况

“智维师”是一个面向老旧设备维保场景的辅助系统。它处理的不是泛化的工业问题，而是一类很具体的工作场景：设备出现异常后，现场人员需要在分散的资料和既有经验之间快速找到依据，完成初步排查，并把这次处理过程整理下来。

## 这个项目对应什么场景

可以把它理解成下面这类场景：

一台老旧设备出现压力波动、异响、温升异常或振动增大。值班人员需要先判断应该看哪些资料、检查哪些部位、哪些情况下可以继续排查、哪些情况下需要停机或上报。处理结束后，还需要把这次经验留下来，方便后续复用。

项目的目标，就是把这条工作链条整理得更顺一些。

## 这个项目具体做什么

当前方案主要包括四部分：

1. 整理说明书、SOP、点检日志、维修记录和历史案例，形成面向维保场景的知识库。
2. 根据故障现象生成结构化的排障结果，包括可能原因、排查步骤、风险提示和依据文档。
3. 根据排障结果整理培训要点和练习内容，支持新人学习和班组带教。
4. 把一次处理过程整理成案例卡，回到知识库中，形成经验沉淀。

用一句更简洁的话概括，这个项目做的是“资料整理、排障辅助、培训支持和案例沉淀”。

## 主要使用者是谁

目前设想的主要使用者有三类：

1. 设备点检和维修人员。
2. 班组长和设备管理员。
3. 新员工、实习生和转岗人员。

因此，这个项目本质上是一个面向实际工作流的应用型方案。

## 为什么这个场景有价值

这个场景的价值主要来自四个方面：

1. 资料通常是有的，但分散在不同载体和不同文件里。
2. 很多处理经验依赖老师傅个人积累，传递成本高。
3. 新人面对故障时，常见问题不是完全不会，而是不知道从哪里开始。
4. 一次处理过程如果没有整理成案例，下次仍然要重新查找和判断。

这几件事都很具体，也都容易转化成项目里的功能和后续验证。

## 项目范围怎么理解

当前项目范围放在老旧设备维保场景，重点是知识整理和流程辅助。它不是面向所有制造业问题的全场景平台，也不把目标放在替代专家判断上。现在这套原型，更适合被理解为一套辅助方案的核心工作台和原理样机。

## 一句话理解

“智维师”是一套围绕老旧设备维保场景，把排障、培训和经验沉淀串起来的辅助方案。
