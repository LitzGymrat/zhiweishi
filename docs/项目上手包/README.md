# 项目上手包

这套文档用于帮助第一次接触“智维师”项目的组员快速建立整体理解。

读完以后，应该能回答下面几个问题：

1. 这个项目在做什么。
2. 为什么选老旧设备维保这个场景。
3. 原型现在做到哪一步了。
4. PoC 具体怎么组织。
5. PoC 之后的工作按什么顺序推进。

## 阅读顺序

建议按下面顺序阅读：

1. `01_项目到底是什么.md`
2. `02_我们为什么做这个项目.md`
3. `03_原型现在做到哪一步了.md`
4. `04_PoC到底要怎么做.md`
5. `05_后续工作怎么推进.md`
6. `06_组员怎么分工.md`
7. `07_开会时可以怎么介绍这个项目.md`

## 每份文档的作用

1. `01_项目到底是什么.md`：建立对项目本身的基础理解。
2. `02_我们为什么做这个项目.md`：说明选题原因和比赛匹配关系。
3. `03_原型现在做到哪一步了.md`：说明当前原型的状态和阶段判断。
4. `04_PoC到底要怎么做.md`：说明这轮 PoC 的目标、流程和产出。
5. `05_后续工作怎么推进.md`：说明 PoC 之后的推进顺序。
6. `06_组员怎么分工.md`：说明后续工作适合怎样拆分。
7. `07_开会时可以怎么介绍这个项目.md`：提供一份简明的组会讲述提纲。

## 如果只想先看核心内容

可以先看下面三份：

1. `01_项目到底是什么.md`
2. `03_原型现在做到哪一步了.md`
3. `04_PoC到底要怎么做.md`
