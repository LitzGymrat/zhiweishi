# 背景证据摘要

## 使用说明

本文件用于固化当前已经确认的背景材料结论，并明确哪些话可以写进计划书，哪些话还不能写满。

## 当前较稳健的结论

1. 东北传统制造业近年处于持续的数字化、智能化升级背景中。
2. 设备运维、巡检、故障诊断和培训已经进入地方政策和企业转型场景表述中。
3. 至少在辽宁的直接案例中，已经出现经验依赖、信息分散、知识沉淀不足、故障排查难等痛点表述。
4. 基于大模型的知识问答或智能体式辅助工具，已经在设备维保场景中出现落地尝试和量化效果描述。

## 当前证据边界

1. 现有材料足以支持“设备维保是可成立的切入点之一”，但不足以支持“东北所有制造企业普遍存在同样程度的问题”。
2. 现有材料可以支持“AI系统适合作为辅助型工具”，但不足以支持“系统可替代专家”。
3. 现有材料可以支持“知识增强问答和智能流程有应用价值”，但不足以支持“多Agent是该问题的最佳架构”。
4. 现有材料对“培训成本较高”这一表述的直接量化支持仍然偏弱，正式文本中应优先使用“新人上手难、培训周期长、经验传承不足”等更稳妥说法。

## 建议写入计划书的表述

在东北制造业数智化升级背景下，设备维保场景已出现经验依赖、知识分散、排障效率受限和经验传承不足等现实问题，本项目据此选择老旧设备维保作为切入点，探索知识增强智能辅助系统的落地路径。

## 不建议直接写入计划书的表述

1. 东北所有制造企业普遍存在完全一致的问题。
2. 本系统可直接替代老师傅或维修专家。
3. 多Agent是该问题的最优技术方案。
4. 本项目已经证明具备大规模产业化效果。

## 当前最值得继续补强的证据

1. 吉林或黑龙江制造企业关于设备维保、经验传承、培训难度的直接案例。
2. 上市制造企业年报、ESG报告中关于设备维保、技能传承、培训投入的表述。
3. 与东北老工业基地设备运维数字化、知识管理相关的学术研究或行业报告。

## 当前背景研究的使用策略

1. 以政策文件支撑“为什么选东北制造业升级”这一层。
2. 以辽宁直接案例支撑“为什么选设备维保”这一层。
3. 以全国补充材料支撑“为什么AI知识增强工具具有技术可行性”这一层。
4. 以小样本访谈、问卷或实验室设备样本补齐“本团队自有验证”这一层。
