# 你们现在接手的是哪一段

---

## 当前阶段是什么

这个项目现在已经从原型开发阶段进入了整理和推进阶段。当前比较清楚的工作顺序是：

1. 先完成 PoC。
2. 再把项目简介、PPT、视频这些材料接起来。
3. 最后继续扩展成更完整的比赛材料。

因此，你们现在接手的是“把现有原型继续往完整作品推进”这一段。

---

## 你们接下来主要负责什么

接下来主要有两块工作会落到你们这里：

### 第一块：把 PoC 真正执行出来

这里需要做的是把测试者、任务、时间、记录表、截图和结果整理这些内容全部接起来，让 PoC 真正落地。

### 第二块：把 PoC 之后的材料继续往前推

PoC 完成以后，后面会自然接上项目简介、PPT、视频和其他材料。你们这一段工作的作用，是把 PoC 结果转成后续材料可以直接使用的内容。

---

## 这个阶段工作的判断标准

这一阶段的工作是否到位，可以直接看几个结果：

1. PoC 有没有按计划执行出来。
2. 原始数据和截图有没有保留完整。
3. PoC 结果有没有整理成可直接使用的结论。
4. 后续材料有没有按顺序接起来。

---

## 为什么这一段重要

当前项目最容易出的问题，往往不在原型本身，而在后续衔接上。比如：

1. PoC 没做完整。
2. 结果没有及时整理。
3. 材料推进顺序不稳。
4. 每个人的讲法不一致。

你们接手的这一段，处理的就是这些问题。

---

## 后续工作的基本节奏

后面这段工作可以一直按下面这个节奏理解：

1. 先做 PoC。
2. 拿到结果表和截图。
3. 用这些结果继续写项目简介和搭 PPT。
4. 再往后接视频和其他材料。

这个顺序比较重要，因为后面的内容都建立在前面的结果上。

---

## 这一段需要和技术组确认什么

虽然你们主要负责组织和推进，但有几项信息需要尽早和技术组确认：

1. PoC 当天使用哪个固定版本的原型。
2. 当前最终确定的 4 个任务是什么。
3. PoC 二用哪个任务做案例回写复用验证。
4. 现场由谁负责技术保障。

这些信息越早固定，后续执行越顺畅。

---

## 这一份的结论

你们现在接手的是项目推进和组织这一段。当前最主要的工作，是把 PoC 做出来，并把 PoC 结果继续接成后续材料。
