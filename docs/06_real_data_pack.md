# 公开真实数据包

## 使用原则

1. 本文件只收录当前已核对过的公开来源，用于项目背景、答辩展示和可行性论证。
2. 这些数据不直接进入故障排查知识库，避免政策、新闻和行业报告污染维保检索结果。
3. 所有数字都优先采用公开来源中的明确表述，避免自行外推。

## 建议答辩时直接使用的三句话

1. 东北制造业数智化升级不是抽象趋势，辽宁、黑龙江、吉林三省都已经公开发布过明确的政策目标、推进进展和企业收益数据。
2. 设备维保中的经验依赖、知识沉淀不足和新人上手难，并不是我们主观想象，辽宁本地公开案例已经直接把这四类痛点点出来。
3. 我们做的不是泛泛而谈的工业大模型，而是把公开已被验证有价值的“工业知识检索 + 故障问答 + 经验沉淀”收缩成一个可比赛、可演示、可落地的轻量方案。
