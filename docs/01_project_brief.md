# 项目定稿方案

## 项目名称

智维师：面向东北中小制造企业老旧设备维保场景的知识增强智能辅助系统

## 一句话定位

针对东北传统制造企业老旧或非标设备维保过程中资料分散、经验依赖强、新人上手慢等问题，构建一个集故障排查、知识检索、培训学习和经验沉淀于一体的本地化智能辅助系统。

## 项目简介

在东北传统制造业持续推进数字化、智能化升级的背景下，设备维保环节仍面临知识资料分散、依赖资深工人经验、排障效率不稳定、经验传承困难等现实问题。尤其在老旧设备和非标设备场景中，设备说明书、SOP、维修记录、故障案例等信息往往分散在纸质文档、电子文件和个人经验之中，导致新员工培训周期长、现场故障排查效率低、重复性问题难以沉淀复用。

本项目聚焦东北中小制造企业老旧设备维保这一具体场景，设计一套以知识整理、检索和结构化辅助为核心的知识增强辅助系统。系统围绕故障排查辅助、文档知识检索、培训学习支持、经验案例回写四类核心任务展开，通过构建设备维保知识库、将检索与结构化生成结合、设计排障卡片输出和案例闭环机制，为一线设备管理人员、新员工和班组管理者提供低成本、可本地部署、可持续迭代的辅助工具。

## 目标用户

1. 设备点检与维修人员
2. 班组长与设备管理员
3. 新员工、实习生和转岗人员

## 核心痛点

1. 设备手册、SOP、巡检规范、维修记录和经验总结分散在多种载体中，检索效率低。
2. 老旧设备和非标设备标准化不足，新员工上手慢，遇到故障依赖老师傅经验。
3. 一次排障过程难以标准化沉淀，同类问题容易反复出现。
4. 中小制造企业数字化能力有限，需要低成本、可本地部署的轻量化工具。

## 解决方案概述

系统围绕以下四个功能闭环展开：

1. 导入设备说明书、SOP、巡检表、常见故障案例与培训材料，构建设备维保知识库。
2. 根据用户输入的异常现象，输出结构化排障卡片，包含可能原因、建议排查顺序、风险提示和依据文档。
3. 面向新员工生成岗位速查卡、常见问题问答和训练题，缩短学习周期。
4. 将真实维修过程整理为案例卡，经过人工确认后回写知识库，逐步实现经验沉淀。

## 应用落地与推广路径

本项目不把“智维师”单纯定义为一个问答产品，而是将其定位为一套面向东北中小制造企业老旧设备维保场景的轻量化知识增强解决方案，原型系统只是其中的核心工作台。

建议的落地路径如下：

1. 第一阶段，以单企业、单车间、2到3类典型老旧设备为试点，完成知识整理、结构化排障、培训支持和案例回写闭环验证。
2. 第二阶段，面向班组长、维修工和新员工形成“本地部署 + 文档治理 + 培训支持 + 案例沉淀”的轻量化交付包，降低中小企业的数字化使用门槛。
3. 第三阶段，逐步扩展到同类装备、园区服务机构或职业培训场景，形成可复制的设备维保知识服务模式。

该路径强调低成本切入、局部先行和逐步扩展，符合东北传统制造业数字化升级中“先解决具体痛点、再推动更广泛应用”的现实节奏。

## 项目边界

1. 本项目定位为辅助型系统，不替代专家判断。
2. 本项目聚焦老旧设备维保，不扩展到全场景工业智能平台。
3. 本项目优先解决知识增强和流程辅助，不把复杂预测性维护作为当前MVP目标。

## 当前结论

该方案已可以作为正式立项方向，后续重点不再是重新找大方向，而是继续补强两类内容：

1. 东北设备维保痛点的直接背景证据
2. 技术原型和演示效果
