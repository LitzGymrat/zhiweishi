**案例回写填写内容**

设备：

```
液压泵站
```

触发症状：

```
油温连续偏高，冷却器状态正常，回油背压偏高
```

实际确认与处理步骤：

```
1. 复核冷却器进出水温差，确认冷却器换热状态正常。
2. 现场测量回油压力，发现回油背压持续偏高。
3. 刘师傅拆检回油管单向阀，发现阀芯卡滞，导致回油不畅。
4. 更换回油单向阀后，低负荷运行20分钟，油温逐步回落。
```

最终处理结论：

```
本次油温偏高不是冷却器故障，而是回油单向阀卡滞导致回油背压偏高、油液循环阻力增大。更换单向阀后，油温恢复正常。
```

经验总结：

```
液压泵站油温连续偏高但冷却器状态正常时，应检查回油背压和回油管单向阀；如果单向阀卡滞，应更换后再低负荷复机验证。
```
