# 参赛材料包拆解

## 一、本文用途

根据东北振兴产业升级专项赛要求，项目最终需要形成：

1. 500字以内项目简介。
2. 创业计划书。
3. 20页以内项目介绍PPT。
4. 其他支撑材料。
5. 项目介绍视频。

本文用于把这些材料和“智维师”当前进展对应起来，避免后续只围绕 demo 打转。

## 二、总原则

参赛材料中，产品原型只占整套作品的一部分。更合理的材料结构应是：

1. 前半部分讲清楚东北具体课题、调研依据和解决方案。
2. 中间部分展示原型系统和核心闭环。
3. 后半部分说明验证结果、落地路径和商业计划。

简介、PPT和计划书中的技术表达只需讲到“足以说明可行性”为止，不建议堆砌模型名、架构名和算法名。

如果材料只展示界面和功能，作品会被理解为“一个做得不错的工具”；如果把问题、验证和落地补齐，作品才更像“一个围绕东北产业升级课题提出的解决方案型项目”。

## 三、项目简介建议结构

500字项目简介建议按以下顺序写：

1. 先交代东北传统制造业升级背景下的具体问题。
2. 再说明你们聚焦的是老旧设备维保知识断层，而不是泛化工业AI平台。
3. 再说明解决方案由知识库、结构化排障、培训支持和案例沉淀构成。
4. 最后交代当前已有原型和未来落地方式。

简介中应优先突出：

1. 赛题贴合度。
2. 场景针对性。
3. 原理样机状态。
4. 落地扩展性。

简介里不建议展开具体模型名称，更不建议把项目写成“工业大模型平台”或“多智能体平台”。

## 四、创业计划书建议结构

建议用七章来组织：

1. 项目背景与东北课题定义。
2. 用户痛点与调研依据。
3. 解决方案与系统闭环。
4. 原型系统与技术路线。
5. 概念验证与效果说明。
6. 落地路径、服务方式与商业模式。
7. 团队分工与实施计划。

其中最容易被忽视、但最需要补强的是第五章和第六章：

1. 第五章要回答“你们怎么证明它有价值”。
2. 第六章要回答“这套东西怎么进入真实场景”。

## 五、PPT建议页序

20页以内PPT建议按以下顺序压缩：

1. 封面页。
2. 东北赛题背景与行业痛点。
3. 具体问题界定。
4. 调研依据与场景证据。
5. 目标用户与使用流程。
6. 解决方案总览。
7. 系统工作闭环。
8. 原型系统概览。
9. 知识库与测试集说明。
10. 排障场景演示。
11. 培训场景演示。
12. 回写场景演示。
13. 技术路线与系统架构（点到为止，说明怎么支撑方案即可）。
14. 当前验证结果。
15. 应用价值与指标。
16. 落地路径。
17. 商业模式与服务形态。
18. 推广扩展方向。
19. 团队与分工。
20. 结尾页。

如果页数紧张，优先保留：

1. 问题页。
2. 解决方案页。
3. 演示页。
4. 验证页。
5. 落地页。

## 六、支撑材料建议目录

建议单独整理以下材料：

1. 政策与行业背景摘录。
2. 样本设备资料目录。
3. 典型故障案例卡样本。
4. 原型截图与流程图。
5. 小样本访谈或问卷结果。
6. 测试任务与对照结果表。
7. 案例回写前后效果说明。

这些材料不一定都放进PPT，但可以作为创业计划书附件和答辩问答时的支撑依据。

## 七、视频建议结构

项目介绍视频建议控制在3到5分钟内，按以下节奏：

1. 30秒讲问题。
2. 30秒讲为什么选东北制造业维保场景。
3. 2分钟演示排障、培训、回写闭环。
4. 30秒讲验证结果。
5. 30秒讲落地和扩展。

视频的重点不是炫功能，而是让评委相信：

1. 这是个真实问题。
2. 你们的方案有针对性。
3. 现在的原型已经有继续推进的价值。

## 八、现阶段最优先补的内容

按照当前进展，建议接下来优先补四样：

1. 一版正式的500字项目简介。
2. 一版20页以内PPT骨架。
3. 一组小样本场景验证数据。
4. 一页明确的落地与商业模式说明。

原型系统已经足够支撑你们进入“材料成型”阶段。此时最优策略不是继续堆功能，而是把现有成果组织成符合创业计划竞赛要求的完整项目包。
