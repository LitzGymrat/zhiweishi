# 临时公网隧道试用说明

这份说明只回答一个问题：如果不租服务器，能不能让外面的组员也直接访问你电脑上跑着的原型？

答案是：可以。最简单的方式是让你自己的电脑继续当主机，再用系统自带的 SSH 开一个临时公网隧道。

## 这种方式适合什么时候

适合下面这种场景：

1. 只是临时给组员或老师试用。
2. 你不想先租服务器。
3. 你本人电脑可以在这段时间保持开机。

不适合长期稳定挂着，因为你一关脚本窗口，公网地址就会失效。

## 你这台电脑需要满足什么

1. 原型本地能正常启动。
2. 你已经在 `.env` 里配好 API Key。
3. 建议保持 `app_mode=poc1_readonly`。
4. 建议设置 `access_password`。

## 最短启动方式

直接双击：

```text
start_poc1_public_tunnel.bat
```

这个脚本会自动做三件事：

1. 先启动本地 `PoC1 只读模式`
2. 再通过 `ssh` 连接 `localhost.run`
3. 在终端里输出一个临时公网地址

如果中途隧道断开，脚本现在会自动重连。

## 你拿到什么结果

启动成功后，终端里会出现一条类似下面这样的地址：

```text
https://xxxxxxxxxxxx.lhr.life
```

把这个链接直接发给别人，对方就可以通过公网访问。

如果你设置了 `access_password`，对方打开后会先输入口令。

如果后面发生自动重连，请以终端里最新出现的 `https://...` 地址为准，旧地址可能会失效。

## 这条路为什么现在最方便

因为：

1. 你不用租服务器。
2. 组员不用装环境。
3. 你继续统一控制 API Key、知识库和演示版本。

## 注意事项

1. 这是临时地址，不适合长期使用。
2. 关闭脚本窗口后，公网地址会失效。
3. 最好只用于 `PoC1 只读模式`，不要拿它开放完整写入版。
4. 如果你当前网络限制 SSH 外连，这条路可能会失败，这时再考虑服务器方案。
5. 临时隧道偶尔断开是正常现象，常见原因是网络抖动、电脑休眠、Wi-Fi 切换或公网隧道服务侧回收。
6. 如果脚本已经自动重连，你需要把终端里最新出现的公网地址重新发给别人。
7. 想尽量稳定一点，最好接稳定网络，并把电脑的睡眠和自动锁屏先关掉。

## 一句结论

如果你现在不想租服务器，但想让外面的人也能访问，最简单的方法就是双击 `start_poc1_public_tunnel.bat`，然后把终端里出来的公网地址发给他们。
