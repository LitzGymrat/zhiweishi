# 数据目录说明

当前原型的知识库数据与背景材料分开管理。

## 维保知识库数据

`documents/` 目录只放维保场景测试集，建议按以下结构组织：

1. `manuals/设备名/`：设备说明书、维护手册、参数摘录
2. `sop/设备名/`：点检SOP、开机SOP、停机SOP
3. `inspection_logs/设备名/`：点检日志、巡检记录
4. `maintenance_logs/设备名/`：班报、维保日志
5. `repair_records/设备名/`：维修工单、检修记录
6. `case_cards/设备名/`：历史案例卡、人工确认后归档的案例卡

页面上传和离线建库都会递归读取 `documents/` 下的上述分类目录。

补充说明：前台早期自动生成、来源标记为“前台案例回写自动归档”的 `case_*.md` 草稿，不再纳入展示知识库和检索索引。

## 背景材料

1. `real_data/`：项目背景和论证材料，仅用于答辩展示，不参与故障检索。
2. `case_output/`：前台案例回写的原始 JSON 存档。

补充说明：

1. `real_data/`：公开来源整理后的真实数据包，用于项目背景、答辩展示和可行性论证。
2. `real_data/` 中的数据默认不进入故障排查知识库，避免政策/新闻材料干扰维保检索结果。
